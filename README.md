# LinguaWorld

A responsive language-learning starter app with onboarding, language selection, lessons, XP, streaks, sample leagues, progress tracking, browser speech tools, and a local-demo sign-up flow.

## Run locally
Open `index.html` in a modern browser. Keep `logo.png` in the same folder as `index.html`.

## Deploy
Upload both `index.html` and `logo.png` to the root of your GitHub Pages repository.

## Account note
The sign-up form is a local prototype only. It stores the learner's name and email in this browser's local storage, does not store passwords, and does not create secure online accounts or cloud sync. A production account system needs an authentication backend.
